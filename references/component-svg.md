# SVG 组件规范

SVG 组件允许直接使用 `<svg>` 标签渲染矢量图形，适合自定义图标、装饰形状或复杂的矢量图。

## 核心属性

- **width / height**: 必须指定。
- **viewBox**: 定义画布的坐标系。
- **children**: 内联 SVG 元素（如 `<rect>`, `<circle>`, `<path>`, `<g>` 等）。

## 布局与样式

- **默认布局**: `display: 'block'`。
- **支持属性**: `fill`, `stroke`, `strokeWidth`, `opacity` 等标准 SVG 属性。
- **注意事项**:
    - 建议使用 `viewBox` 以确保图形在不同尺寸下正确缩放。

## 示例代码

### 1. 基础用法 (简单形状)

```jsx
<svg width={100} height={100} viewBox='0 0 100 100'>
    <circle cx='50' cy='50' r='40' fill='#3b82f6' />
</svg>
```

### 2. 综合示例 (复杂路径)

```jsx
<svg width={24} height={24} viewBox='0 0 24 24'>
    <path d='M12 2L2 7l10 5 10-5-10-5zM2 17l10 5 10-5M2 12l10 5 10-5' fill='none' stroke='#64748b' strokeWidth='2' />
</svg>
```

## 最佳实践

- **保持简洁**: 优先使用 FAIcon，仅在需要特殊自定义图形时使用 SVG。
- **坐标对齐**: 确保 `viewBox` 与 `width/height` 比例一致，避免图形变形。

## 🚨 时间轴/圆球结构图坐标硬规则（2026-09-04 三连错教训，必读）

**「竖轴 + 圆球骑轴 + 节点序号/文字」类结构图（P6/P9/P10 型），禁止把 SVG 内坐标与容器 absolute 坐标混用**——两套坐标系必须换算，否则序号/文字整体错位（实测 P6 偏上 156px、P9 偏左 32px、P10 压底部）。

### 1. 坐标系换算铁律（最常见错因）

- SVG 内 `<circle cy>` 是 **SVG 画布坐标**（相对 svg 左上）；外层 absolute Box 的 `top` 是**相对容器的坐标**。
- 若 SVG 自身 `top: T`（相对容器），则圆球中心的**页面/容器 y = T + cy**；任何与圆球对齐的 absolute 元素（序号、文字）的 top 必须用 `T + cy - 偏移`，**不能直接用 cy**。
- ❌ 错：`<svg style={{top:94}}><circle cy=150/></svg>` + 文字 `<Box top={150-62}>`（少加 94 → 偏上）
- ✅ 对：`<svg style={{top:94}}><circle cy=150/></svg>` + 文字 `<Box top={150 + 94 - 标题半高}>`

### 2. 序号必须居中于圆球（left = cx − 序号框宽/2）

- 圆球 `cx=170 r=26`，序号框宽 26 → `left: 170-13`；不要写 0 或随手值（P9 写 left:0 偏左 32px）。

### 3. 文字标题对齐圆球中心，用公式不用猜

- 文字块 `top = T(圆球所在 SVG top) + cy − 标题行高/2`（让标题行中心 = 圆球中心）。
- ❌ 错：随手减 50/62/70/84（每页不同说明是猜的，必然错位）。
- ✅ 对：标题 fontSize 21 → 行高约 25 → top = T + cy − 12 附近。

### 4. SVG 高度必须装下所有圆球（防底部被裁）

- 圆球最底 = max(cy + r)。`svg height` / `viewBox` 高 **必须 ≥ max(cy)+r**，否则底部圆球被裁（P6 cy440+r26=466 > h456 → 底部圆被切）。轴 line 终点同理 ≤ height。

### 4.5 内容节点四周留 ≥8px 安全边距（防边缘削边，P10 左截教训）

- SVG 转 PNG 光栅化时，**贴 viewBox 0 边界（x=0/y=0）或出界的图形会被削边/抗锯齿裁掉一丝**（P10 圆球 cx26-r26=0 左缘恰好贴边 → 左边被截）。
- 内容节点圆球/线/矩形：四边距 viewBox 边界 ≥8px（`cx-r ≥8`、`cy-r ≥8`、`cx+r ≤W-8`、`cy+r ≤H-8`）；SVG 内坐标整体右移/下移留白即可。
- 例外：**满幅装饰大圆环**（r ≥ 短边 40%，封面/背景装饰环）故意贴边是设计，validate 已豁免，不受此限。
- validate 现自动检查：小圆球贴/出 viewBox 边界报错（含左/右/上/下），装饰大环不报。

### 5. 文字块总高必须 < 圆球间距（防段间/底部重叠）

- 标题对齐圆球中心后，说明文字往下延伸；若块底 > 下一圆球中心或容器底 → 压到下一段/底部元素（P10 第 3 段压到"复盘结论"）。
- 布局前先估：标题行高 + 说明行数×行高 ≤ 圆球间距（≈ 相邻 cy 差），且最后一个圆球下方给说明+页脚留 ≥ 80px。

### 6. 更稳的替代写法（推荐，免心算）

- 圆球可以不用 SVG：用 `<Box borderRadius:999 border:'4px solid #EA580C'>` 画圆（引擎支持），轴用细 Box；这样**圆球、序号、文字全在同一坐标系（都是容器 absolute/flex）**，无 SVG↔容器换算，错位风险归零。
- 圆球结构图优先考虑此写法；确要用 SVG 圆球，必须逐条过上面 1-5。
