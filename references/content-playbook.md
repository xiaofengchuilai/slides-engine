# 内容范式手册（content-playbook）

> 解决的核心问题：**同样的引擎和设计，为什么有的 PPT 内容深、有的空喊口号？**
> 答案是内容深度不能靠模型临场发挥，必须按 PPT 类型显式约束"必讲什么、禁讲什么、必须具体到什么程度"。

**使用规则**：STORY 阶段，先按 PPT 类型找到对应范式，按"必讲骨架"组织内容，逐条过"空话黑名单"和"细节门禁"。未过门禁 → 补充具体细节，禁止进入 DESIGN 阶段。

---

## 通用铁律（所有类型适用）

1. **空话黑名单**（出现即返工）："责任""创新""共赢""赋能""协同""使命担当""砥砺前行""凝心聚力"——这类词正确但**无信息量**，除非后面紧跟"具体怎么做/具体数字"。
2. **细节门禁**：任何承诺/成果/计划，必须回答"具体做什么 + 什么数字/时间 + 对谁负责"。
3. **"所以呢"原则**：每个数据/结论后面必须有一句判断（含义/影响/行动），不能只摆事实。
4. **人物主体型 PPT**（就职/述职/自我介绍）必须先"立人"再"立事"——观众先相信你这个人，才听你的承诺。

---

## 1. 就职演说

**必讲骨架**（顺序不可乱）：

```
① 开场感谢（简短，不铺陈）
② 我是谁 —— 个人背景：专业、经历、能力标签（3-5个具体标签）
③ 成长轨迹 —— 时间轴：3-5 个关键节点（年份+事件+一句收获）
④ 我看岗位 —— 行业趋势 / 团队现状 / 岗位使命（3维度，每个有具体判断）
⑤ 我的承诺 —— 3-5 项，每项必须"具体行为 + 可验证标准"
⑥ 行动计划 —— 30/60/90 天分段，含具体动作和数字
⑦ 结束 —— 一句有力的收束 + 落款
```

**空话黑名单**（就职专用）："我一定不辜负信任""带领大家走向辉煌""共同创造美好明天"。

**细节门禁**：
- 个人背景必须有**具体经历**（学校/公司/岗位），不能是"知名高校""头部企业"这种模糊表述
- 成长轨迹必须有**年份 + 具体事件**（如"2022 年带领团队突破 XX 目标"）
- 承诺必须有**可验证标准**（如"30 天内完成全员 1 对 1 沟通"，不能只说"公平公正"）
- 行动计划必须有**数字 + 时间**（30/60/90 天各做什么）

## 2. 述职报告

**必讲骨架**：

```
① 工作回顾 —— 本周期目标 vs 实际完成（数据对比）
② 亮点成果 —— 2-3 个，每个"做了什么 + 结果数据 + 判断"
③ 问题反思 —— 1-2 个真实问题 + 根因 + 改进
④ 下周期计划 —— 目标 + 关键举措 + 时间节点
⑤ 资源诉求（可选）
```

**细节门禁**：成果必须有数据（增长 X%/完成 N 件/节省 Y 成本）；问题必须具体（不是"沟通不足"而是"跨部门需求响应平均延迟 3 天"）。

## 3. 产品发布

**必讲骨架**：

```
① 用户痛点 —— 具体场景 + 痛点（不泛泛说"效率低"）
② 解决方案 —— 产品怎么解决（功能 + 价值）
③ 核心亮点 —— 3 个差异化能力
④ 演示/场景 —— 一个真实使用场景贯穿
⑤ 价值证明 —— 数据/案例/客户证言
⑥ 行动号召 —— 试用/购买/预约
```

**细节门禁**：痛点必须具体到"什么人、什么场景、现在怎么痛苦"；亮点必须有对比（比现有方案好在哪）。

## 4. 季度/工作汇报

**必讲骨架**：

```
① 目标回顾 —— 季度目标是什么
② 完成情况 —— 数据 vs 目标（达成率）
③ 亮点与不足 —— 各 1-2 条，具体
④ 问题与对策 —— 问题 + 根因 + 下一步
⑤ 下季度计划 —— 目标 + 里程碑
```

**细节门禁**：完成情况必须数据化（%达成/绝对数/环比）；不足必须有对策，不能只列问题。

## 5. 路演融资

**必讲骨架**：

```
① 市场机会 —— 市场规模 + 增长 + 判断
② 问题 — 用户痛点
③ 解决方案 —— 产品/服务
④ 商业模式 —— 怎么赚钱（具体）
⑤ 竞争壁垒 —— 为什么是我们
⑥ 团队 —— 关键成员 + 背景
⑦ 财务/里程碑 —— 已有数据 + 未来预测
⑧ 融资需求 —— 要多少钱 + 怎么花
```

**细节门禁**：市场规模必须数字 + 来源判断；商业模式必须说清收入/成本结构；融资需求必须明确金额 + 用途 + 里程碑。

## 6. 学术答辩

**必讲骨架**：

```
① 研究背景 —— 问题 + 现状 + 缺口
② 研究问题 —— 明确的研究问题/假设
③ 方法 —— 技术路线 + 创新点
④ 实验/结果 —— 数据 + 验证
⑤ 结论与贡献 —— 结论 + 学术/应用价值
⑥ 展望 —— 局限 + 未来工作
```

**细节门禁**：数据/公式/结论必须真实可追溯，禁止杜撰；方法必须有创新点说明。

## 7. 培训/分享

**必讲骨架**：

```
① 目标 —— 听完能做什么（能力目标，不是"了解"）
② 背景/问题 —— 为什么需要这个
③ 核心内容 —— 3-5 个要点，每个"是什么 + 怎么做 + 例子"
④ 练习/应用 —— 一个可操作的练习或 checklist
⑤ 总结 + 资源
```

**细节门禁**：每个要点必须有具体例子或操作步骤；目标必须是"能做什么"而不是"了解什么"。

## 8. 政务/党建汇报

**必讲骨架**：

```
① 总体情况 —— 做了什么（数据 + 成效）
② 重点工作 —— 2-3 项，每项"举措 + 成效 + 数据"
③ 亮点/创新 —— 具体做法 + 可推广价值
④ 问题与不足 —— 具体问题 + 改进
⑤ 下一步 —— 计划 + 时间表
```

**细节门禁**：成效必须数据化（覆盖人数/完成率/满意度）；问题必须具体，禁止"还需加强""有待提升"这种空话。

---

## 使用时的自检

生成 STORY.md 前，逐条对照：

- [ ] 我找到了这份 PPT 对应的类型范式了吗？
- [ ] 必讲骨架的所有模块都覆盖了吗？
- [ ] 有没有出现空话黑名单里的词（且后面没跟具体内容）？
- [ ] 每个承诺/成果/计划都有"具体 + 数字 + 时间"吗？
- [ ] 如果是人物主体型，有没有先"立人"（个人背景 + 成长轨迹）？
- [ ] 每个数据后面都有"所以呢"判断吗？

## 视觉元素丰富度 checklist（每页写 .slide 时逐条过）

> 解决的核心问题：**内容对了、骨架对了，但页面还是"单调、元素少、没细节"**。
> 根因：只搭了"大骨架"（色块+文字+图），没做"细节装饰"。以下 6 要素是高质量页面的共性，容易缺失。

**每页至少满足以下 6 条里的 4 条，否则 = 单调，返工：**

1. **卡片圆角 + 独立卡片容器**：内容区块用 `borderRadius: 12-16` 的圆角卡片承载，不用直角色块裸放文字。卡片间用浅灰边框或浅色底区分。

2. **编号块（圆形/方形带数字）**：凡是有 1/2/3 或 01/02/03 条目的，数字必须放在一个色块里（圆形或方形 `borderRadius`），不能是裸文字数字。

3. **装饰线（短横线分隔）**：标题和正文之间、卡片头部，用一条 2-4px 高的短色块横线分隔（长度约 40-60px），增强排版细节。

4. **颜色分层 ≥3 层**：每页文字至少 3 种颜色层级（如：编号色 + 标题色 + 说明灰），不能只有"标题 + 正文"两层。年份/数字用强调色，标题用主色/深色，说明用灰色。

5. **结构化视觉引导**：时间线用圆点标记节点、流程用箭头/chevron、卡片用图标或编号锚点——不能只是文字列表平铺。

6. **主题归属标注**：每页左下角或固定位置，放一行小字（如"就职演说 · 个人篇"），标注当前页面所属章节/主题，全篇位置一致。

**反例（单调）**：白底 + 纯文字列表 + 只有橙色标题 + 黑色正文，无圆角卡片、无编号块、无装饰线、无颜色分层。
**正例（丰富）**：圆角卡片承载内容 + 编号块（圆形/方形）+ 短装饰线 + 三色分层（强调数字/主色标题/灰色说明）+ 时间轴圆点 + 左下角主题标注。
