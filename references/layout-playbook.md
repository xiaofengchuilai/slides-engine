# 信息组织范式（layout-playbook）

> 从专业演示文稿逐页拆解提炼的"信息组织方式"。
> 解决的核心问题：**内容对了、元素齐了、也 flex:1 铺满了，但页面还是"空洞、松散、不够精致"**。
> 根因：不是"内容不够"或"元素不够"，是**信息组织方式不对**——常见问题是"上下堆叠 + 碎句"，而高完成度的版式是"左右不对称 + 大锚点 + 完整结论句 + 完整段落"。

---

## 8 个核心范式（每页对照，缺一不可）

### 1. 页面用「左右不对称」，不用「上下堆叠」

- 高质量页面几乎都是**左窄栏 + 右宽栏**（或左大锚点 + 右列表），不是"标题在上、内容在下"。
- 版式选择见 story-principle.md §版式速查：左标题+右内容 / 左大图+右文字 / 非对称双栏，占 ≥40%。

```
错误：标题 → 下面三个卡片横排（上下堆叠感强）
正确：左窄栏（引导/大数字） + 右宽栏（3 卡片竖排）
```

### 2. 每页有一个「大视觉锚点」占一侧

- 承诺页：左侧 220×220 圆 + 大数字"5"
- 行动页：右侧 320×558 深色指标栏
- 目录页：左侧 320×520 深色块

**锚点是"视觉重量"的来源**，不能缺。一个页没有大色块/大数字/大图，就"轻飘飘"。

### 3. 标题必须是「完整结论句」，不是碎词

- ✅ "行业趋势：变革加速，不进则退"
- ✅ "团队现状：有基础，更有潜力"
- ❌ "行业 · 不进则退"（碎词）

完整结论句 = 主题 + 冒号 + 结论。这是 Action Title（consulting 分支里的硬规则）。

### 4. 正文是「完整段落」，不是一句话

- 专业稿每个维度正文是 2-3 行完整段落，写满"现状 + 判断 + 影响"。
- 常见误区是写一句就停（如"数字化转型窗口期，客户需求快速迭代，竞争对手加速进化"）。

**每个观点的正文至少 2 行、写满"是什么 + 为什么 + 所以呢"。**

### 5. 每个条目是「小编号块 + 完整标题 + 两行正文」固定三段式

- 编号块很小（48×48 或 29×27），是精致点缀，不是 56×56 的大方块。
- 标题和正文左对齐，行距紧凑。

### 6. 色彩有明确的语义系统（不是随便配色）

| 色 | 用途 |
|---|---|
| 主色（深） | 标题、大色块、锚点底 |
| 强调色 | 编号块、引导金句、关键数字 |
| 中性浅色 | 卡片底、标签底 |
| 灰 | 说明文字、脚注 |

每页 4-5 种色，各司其职，层级分明。

### 7. 底部固定「主题标注 + 页码」

每页左下"主题 · 章节名"，右下"NN / TOTAL"，全篇位置一致。

### 8. 复杂页用「阶段/里程碑 + 数据锚点」

- 行动计划页：左 3 阶段（标题+副标题+3个带"+"的事项），右"关键衡量指标"栏（90%/3+/100% 大数字）。
- 数据页必须有"大数字锚点"压阵，不是纯文字列表。

---

## 自检：我的页面为什么空洞？

对照下面 6 问，全答"是"才不空洞：

- [ ] 页面是左右不对称，还是上下堆叠？
- [ ] 有 ≥1 个大视觉锚点（大数字/大色块/大图）占一侧吗？
- [ ] 标题是完整结论句（主题：结论），还是碎词？
- [ ] 每个观点正文 ≥2 行、写满"是什么+为什么+所以呢"？
- [ ] 条目是"小编号块+完整标题+两行正文"固定结构？
- [ ] 色彩有语义分层（主/强调/浅/灰）？

**任何一条答"否"，就是空洞的来源，返工。**
